## Source ingestion workflow

When the user adds a new source to `inbox/` and asks you to ingest it:

1. Read the full source document and move it to the `sources/` folder with a
   unique, human-readable name capturing its content
2. Discuss key takeaways with the user before writing anything
3. Create a summary page in `wiki/` named after the source
4. Create or update concept pages for each major idea or entity
5. Add wiki-links ([[page-name]]) to connect related pages
6. Update `wiki/index.md` or the relevant hub page with new entries and one-line
   descriptions

A single source may touch 10-15 wiki pages. That is normal.
