## Source ingestion workflow

When the user adds a new source to `.agent-workspace/inbox/` and asks you to
ingest it:

1. Read the full source document and move it to `.agent-workspace/sources/` with
   a unique, human-readable name capturing its content
2. Discuss key takeaways with the user before writing anything
3. Create a summary page in `.agent-workspace/wiki/` named after the source
4. Create or update concept pages for each major idea or entity
5. Add wiki-links ([[page-name]]) to connect related pages
6. Update `.agent-workspace/wiki/index.md` or the relevant hub page with new
   entries and one-line descriptions

A single source may touch 10-15 wiki pages. That is normal.
