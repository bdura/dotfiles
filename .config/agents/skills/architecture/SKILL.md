# Architecture

Explore the project and generate a short summary. Make sure to list important
features as well as the main design choices.

Update `ARCHITECTURE.md` to make it reflect your findings. Further investigate
any discrepancy to make sure the document is up to date and correct.

## Which shape to write

If the document does not exist, create it following the
[template](references/template.md).

If it does exist, keep its existing structure and headings: update the content in
place, correct what has drifted, and add what is missing in the document's own
idiom. Do not restructure a document that someone deliberately shaped.

Once the content is right, if the structure diverges from the template, say how
and ask whether to restructure it now, file it with /file-issue, or leave it.
Restructuring is its own commit, never folded into a content update.
